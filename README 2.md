# Invitation Project — Remaining Build Prompts

This package contains phases 06–25.

Use them sequentially. Do not paste all phases into the coding agent at once.

Recommended process:
1. Give the agent the Master Project Prompt.
2. Give Agent Operating Rules.
3. Give the tool-specific initialization prompt.
4. Run each numbered phase in order.
5. Require the agent to stop and report after each phase.
6. Review the report and git diff before moving to the next phase.

Existing phases 00–05 should remain with the project specification.

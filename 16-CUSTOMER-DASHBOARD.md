# 16 — CUSTOMER DASHBOARD

Build the customer dashboard.

The dashboard should be simple because the customer is not an invitation designer.

Main areas:
- Overview
- My Invitation
- Guests
- Gifts
- Media
- Livestream
- Account

Do not build a customer invitation builder.

The customer enters information through the structured invitation creation flow.

Dashboard should show:
- invitation status
- selected package
- selected template
- event countdown
- invitation link
- share action
- feature availability
- guest/RSVP summaries
- gift summary where applicable
- media summary where applicable

Submitted invitation:
- read-only to customer
- no editing controls
- clear explanation that admin assistance is required for changes

After event date:
- invitation remains accessible
- features remain accessible
- countdown displays completed/event passed state

Use TanStack Query for server state.
Do not add Zustand.

Responsive mobile-first dashboard.
